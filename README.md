One image that sums up the world's news of **Tuesday 24 November 2026**:
46 stories across 9 regions — a Beaver supermoon meeting the Seven
Sisters, Taipei steadying its markets, Tokyo reopening, a blast due in
Iowa standing halted, and nine Champions League ties lighting up the
night — drawn as a cream broadsheet front page with 13 illustrated
stories, a numbered world map, a UTC timeline, six big numbers, and a
red DATE CHECK box naming the big stories of 22–23 November that were
deliberately left out.

[See the bounty on make.fun](https://make.fun/bounty/news-image-20261124)

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the shipped
`entry.png` (1024×1024) to `$MAKEFUN_OUTPUT_DIR/entry.png`
(default `/output`). The two graded runs write identical bytes.
